## ✨ 特性

- 🪟 **两种形态** —— 默认 **194 × 74** 玻璃小窗，每 3 秒在 CPU / GPU / 帧率 / Wi-Fi / 蓝牙间轮播；**单击小窗**展开全部卡片与曲线的完整面板。
- 📈 **可折叠曲线图** —— 每个模块保留最近 **120 个采样点**，点卡片标题即展开 / 收起。
- 🎯 **只报真实读数** —— PDH 真实睿频频率、NVIDIA NVML 显卡直读、WlanAPI 真实 RSSI、GATT 蓝牙电量；读不到就明确标注原因，**绝不编造数值**。
- 🎮 **前台应用帧率** —— 优先 PresentMon（校验签名哈希后才启动），不可用时自动回退屏幕刷新采样，只统计当前前台窗口。
- 🕶 **鼠标穿透** —— 锁定后点击直接落到后面的应用，`Ctrl+Alt+L` 随时切换；锁定后透明度可调（0–100%）。
- 🎛 **完全可控** —— 每一项指标可单独开关、卡片横 / 竖排、界面缩放 60%–140%、开机自启动、始终置顶，全部写入 `config.json`。
- 📦 **托盘常驻** —— 关窗即最小化到托盘，进程不退；托盘菜单可直接重启程序（无需重找 UAC）。
- 🌐 **网络分开统计** —— Wi-Fi 与有线各自独立的收发速率 / 链路速率 / 延迟探针，互不混算。

## 🪟 两种形态

| 小窗（默认） | 完整面板（单击后） |
| --- | --- |
| 单个指标 + 大号数字 + 轮播进度条 | CPU / GPU / 帧率 / Wi-Fi / 蓝牙全部数字卡片 + 可折叠曲线图 |

- 小窗底部细进度条显示轮播节奏。
- 展开后点标题栏 **⤢**（或托盘菜单）回到小窗，两种形态的窗口位置分别记住。
- 位置、锁定状态、透明度、排列方向、界面缩放、图表折叠状态都持久化到 `config.json`。

## 🚀 快速开始

> 环境：**Windows 10 / 11** + **Python 3.10+**；GPU 指标需要 NVIDIA 显卡。

```bat
双击 启动监控.bat
```

| 场景 | 用哪个 |
| --- | --- |
| 日常使用 | **`启动监控.bat`**（首次自动创建 `.venv` 并安装依赖） |
| 查看**游戏实时帧率** | **`以管理员身份启动.bat`**（弹一次 UAC） |
| 排查报错 | **`调试启动.bat`**（保留控制台输出） |

首次启动后，右键托盘图标 → **设置…** 即可配置开机自启动、置顶、穿透与透明度。

## 📡 显示内容

| 模块 | 数字 | 曲线图 |
| --- | --- | --- |
| CPU | 使用率、实时频率（含睿频）、热区温度、核心 / 线程 | — |
| GPU | 使用率、温度、显存、功耗、频率、风扇 | 帧率 |
| 帧率 | 实时 FPS + 进程名（只统计**前台应用**） | — |
| Wi-Fi | SSID、信号 dBm/%、延迟 + 测速 IP、收发速率、链路速率、信道、PHY | 信号 / 速率 / 延迟 |
| 有线网络 | 延迟 + 测速 IP、收发速率、链路速率、IPv4 | 延迟 |
| 蓝牙 | **仅已连接**设备、电量、实时 BLE 信号 dBm、连接状态 | 各设备信号 |

> 完整的数据来源、精度差异说明（为什么和任务管理器数字不一样）、
> Windows 定位权限开启步骤、帧率双通道原理 → **[docs/说明书.md](docs/说明书.md)**

## 🎛 交互速查

| 操作 | 说明 |
| --- | --- |
| **单击小窗** | 展开完整面板 |
| 拖动小窗 / 面板 | 移动位置（自动保存） |
| 标题栏 ⤢ | 收起为小窗 |
| 标题栏锁 / `Ctrl+Alt+L` | 鼠标穿透（锁定）+ 按设定透明度变透明 |
| 标题栏图钉 | 始终置顶 |
| 标题栏 ✕ | **最小化到托盘**（不是退出） |
| 右键小窗 / 面板 / 托盘 | 菜单：展开收起、穿透、定位设置、重启、**退出程序** |
| 托盘右键 → 设置… | 自启动、置顶、穿透、锁定透明度、界面缩放、**自定义显示内容** |
| 点 Wi-Fi / 蓝牙卡片标题 | 展开 / 收起该卡片曲线图 |

## ❓ 常见问题

| 问题 | 解决 |
| --- | --- |
| 小窗点不动 | 已开启鼠标穿透（右上角有小锁），按 `Ctrl+Alt+L` 解锁 |
| 托盘图标找不到 | Windows 11 收进了 **^** 溢出区，点开即可 |
| Wi-Fi 显示"需定位权限" | 设置 → 隐私和安全性 → 定位 → 打开"让桌面应用访问你的位置"（[详细步骤](docs/说明书.md#windows-定位权限)） |
| CPU 温度偏高 | 这是主板 ACPI 热区读数，游戏本高负载 70–80 °C 属正常范围 |
| 界面太大 / 太小 | 设置 → 界面缩放（60%–140%），松手自动重启生效 |
| 蓝牙没有电量 | 经典蓝牙 Windows 不提供电量，只有 BLE 设备可读 |

全部问题与原理说明见 **[docs/说明书.md](docs/说明书.md)**。
