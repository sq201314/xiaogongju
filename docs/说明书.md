# 性能监控桌面悬浮窗

> 📌 本文是**完整说明文档**（数据来源与精度、定位权限、安全说明、全部 FAQ）。
> 项目介绍首页见 [README.md](../README.md)。

常驻桌面的硬件状态小部件（Python + PySide6）。默认只有一个 **194 × 74** 的玻璃拟态小窗，
在 CPU / GPU / 帧率 / 温度 / Wi-Fi / 蓝牙之间自动轮播；**单击小窗才展开完整面板**。

## 两种形态

| 小窗（默认） | 完整面板（单击后） |
| --- | --- |
| 单个指标 + 大号数字 + 轮播进度条 | CPU / GPU / 帧率 / Wi-Fi / 蓝牙全部数字卡片 + 可折叠曲线图 |

- 小窗每 3 秒切换一个指标，底部细进度条显示轮播节奏。
- 展开后点标题栏的 **⤢** 按钮（或托盘菜单）回到小窗，窗口位置自动记住。
- 两种形态的位置、锁定状态、锁定透明度、排列方向、界面缩放、图表折叠状态都写入 `config.json`。

## 显示内容

| 模块 | 数字 | 曲线图 |
| --- | --- | --- |
| CPU | 使用率、实时频率（含睿频）、热区温度、核心/线程 | — |
| GPU | 使用率、温度、显存、功耗、频率、风扇 | 帧率 |
| 帧率 | 实时 FPS + 进程名；优先 PresentMon，失败时用屏幕刷新采样，只统计**当前前台应用** | — |
| Wi-Fi | SSID、信号 dBm/%、**Wi-Fi 延迟 + 测速 IP**、Wi-Fi 网卡的收发速率、链路速率、信道、PHY | 信号强度 / 收发速率 / 延迟 |
| 有线网络 | **有线延迟 + 测速 IP**、有线网卡的收发速率、链路速率、IPv4 地址 | 有线延迟 |
| 蓝牙 | **仅已连接**的设备、电量、实时 BLE 广播信号 dBm、连接状态 | 各设备信号强度（仅广播期间有值） |

Wi-Fi 与有线网卡分别按适配器统计，互不混算。蓝牙每 3 秒重新枚举一次，
新连接/新配对的设备会自动出现（BLE 设备会自动读一次电量并缓存 3 分钟）。
每个数值标签都预留了固定显示宽度，横向卡片也是固定宽度，数值刷新不会让面板或卡片来回跳动。
数值按阈值变色（黄 / 红），曲线保留最近 120 个采样点。
把鼠标停在指标名上可以看到该数值的取数方式。

## 运行

双击 **`启动监控.bat`**（首次会在 `.venv` 建虚拟环境并安装依赖）。

需要显示**游戏实时帧率**时用 **`以管理员身份启动.bat`**（弹一次 UAC）。
排查问题用 **`调试启动.bat`**，会保留控制台报错。

## 交互

| 操作 | 说明 |
| --- | --- |
| 单击小窗 | 展开完整面板 |
| 拖动小窗 | 移动位置（位置自动保存） |
| 标题栏 ⤢ | 收起为小窗 |
| 标题栏锁图标 / `Ctrl+Alt+L` / 托盘菜单 | 鼠标穿透（锁定），同时按设定透明度变透明 |
| 标题栏图钉 | 始终置顶（与设置窗口里的开关同步） |
| 右键（小窗或面板）/ 托盘图标 | 菜单：显示隐藏、展开收起、穿透、定位设置、重置位置、**退出程序** |
| 托盘图标右键 → 设置… | 打开玻璃风格设置窗口：开机自启动、始终置顶、鼠标穿透、锁定后透明度 |
| 设置 → 布局 → 卡片横向排列 | 打开后 CPU / GPU / 网络 / 蓝牙卡片并排成一条横向面板；关闭恢复当前的竖向堆叠 |
| 设置 → 界面缩放 | 60%–140% 只缩放性能监控悬浮窗（小窗 + 完整面板）；设置窗口和托盘保持原尺寸，调整后自动重启应用生效 |
| 设置 → 自定义显示内容 | 逐级进入 CPU / GPU / 网络 / 蓝牙，再逐个开关要显示的指标（如温度、显存、帧率曲线），修改后立即生效并保存 |
| 点 Wi-Fi / 蓝牙卡片标题 | 展开 / 收起该卡片的曲线图 |
| 标题栏 ✕ | **最小化到系统托盘**（窗口隐藏，进程仍在运行），首次会弹提示告诉你怎么退出 |
| 托盘右键 → 退出程序 | 真正退出 |
| 托盘右键 → 重启程序 | 用当前权限重新启动（改完配置/更新后不用再找 UAC） |

> 托盘图标可能被 Windows 11 收进任务栏的 **^** 溢出区，点开就能看到；
> 也可以直接在小窗/面板上右键 → 退出程序，不需要找托盘。

程序会绑定生命周期：启动它的进程（终端/宿主程序）一旦结束，悬浮窗会自动退出，
不会留下孤儿进程；PresentMon 子进程也放在 kill-on-close 的 Job 里，主程序被强制结束时一并清理。

锁定后窗口带 `WS_EX_TRANSPARENT`，点击直接落到后面的应用；此时小窗右上角显示一个小锁图标，
再按 `Ctrl+Alt+L` 或走托盘菜单解锁即可单击展开。背景会同时淡出到设置里「锁定后透明度」的程度，
后面的画面清晰可见，文字保持清晰。所有可调选项（包括锁定透明度、开机自启动、始终置顶）都集中在
托盘右键 →「设置…」窗口里，不会出现在悬浮窗本体上，修改后写入 `config.json`，下次启动继续生效。

设置窗口沿用悬浮窗的玻璃风格。要显示的指标放在二级菜单里：设置 →「自定义显示内容」→ 选择
CPU / GPU / Wi-Fi / 有线网络 / 蓝牙 → 在分类页逐项开关。关闭的指标会同时从完整面板和小窗轮播中
移除；整组关闭会隐藏对应卡片。隐藏列表保存在 `config.json` 的 `hidden` 里。

## 数据来源与精度

| 指标 | 来源 | 说明 |
| --- | --- | --- |
| CPU 使用率 | `psutil` | — |
| CPU 频率 | PDH `\Processor Information(_Total)\% Processor Performance` × `Processor Frequency` | 真实睿频后的当前频率（如 3.4 GHz），不是固定基频 |
| CPU 热区温度 | PDH `\Thermal Zone Information(*)\High Precision Temperature` | 主板 ACPI 热区，读数随负载升降；不等同于核心封装温度 |
| GPU | NVML（NVIDIA） | 使用率、显存、温度、功耗、SM 频率均为显卡真实读数 |
| 刷新率 | `EnumDisplaySettings` | 当前显示模式的实际刷新率 |
| 帧率 | `tools/PresentMon.exe`，失败时回退到前台窗口的屏幕刷新采样 | 优先显示前台窗口进程的帧率；ETW 不可用时按画面变化次数统计，前台无出帧时显示 0 并标注「无出帧」 |
| Wi-Fi | WlanAPI（`wlanapi.dll`） | 真实 RSSI、协商速率、信道、PHY；需要 Windows 定位权限 |
| Wi-Fi 收发速度 | 该 Wi-Fi 网卡自身的字节计数 | 与有线网卡完全分开统计 |
| 有线收发速度 | 该有线网卡自身的字节计数 | 链路速率取适配器协商速率（如 1000 Mbps） |
| 延迟 | TCP 握手到公共节点（223.5.5.5:443 等） | 每个网卡各有一个探针，socket 绑定到该网卡的 IP；面板会显示实际测速 IP |
| 蓝牙 | WinRT：经典 + BLE 的“已配对/已连接”选择器合并后，**只保留已连接设备** | BLE 电量读 GATT `0x180F`（缓存 3 分钟），每 3 秒重新枚举；信号优先取 `BluetoothLEAdvertisementWatcher` 的实时广播 RSSI，设备停止广播时回退到系统设备关联缓存值 |

### 为什么有些数字和别的软件不一样

| 指标 | 差异原因 |
| --- | --- |
| CPU 使用率 | 这里是最近约 1 秒的全核平均；各软件采样窗口不同，瞬时值会差几个百分点 |
| CPU 频率 | 这里用 `基频 × %ProcessorPerformance` 计算当前频率（含睿频）；任务管理器里的“基准速度 2.20 GHz”是基频，不是当前频率 |
| 热区温度 | 这是主板 ACPI 热区传感器，通常比 CPU 核心封装温度高 10–20 °C；核心温度需要管理员权限的专用驱动才能读 |
| GPU | 只显示独显（NVIDIA NVML）；核显占用不在此列 |
| 帧率 | 优先用 PresentMon 的真实呈现帧数；本机 ETW 丢事件严重时会自动改用“前台窗口画面变化次数”，与视频/游戏内部计数基本一致，静态画面为 0 |
| Wi-Fi 信号 | 有定位权限时是 WlanAPI 的真实 dBm；没有权限时显示“需定位权限”而不是编造数值 |
| Wi-Fi 信道 | 信道走的是独立查询，**不需要定位权限**，所以即使信号读不到也会显示（如 48） |
| 收发速率 | 现在分别统计 Wi-Fi 网卡和有线网卡，不会把有线的流量算到 Wi-Fi 头上 |
| 蓝牙信号 | 优先显示 BLE 广播里实测的实时 RSSI；设备连上后停止广播时回退到 Windows 设备关联缓存值（是真实测量，但可能有延迟；鼠标悬停会标注来源） |
| 蓝牙电量 | 不受定位权限影响；BLE 设备可用 GATT 电池服务读取 |

### Windows 定位权限

Windows 11 把 Wi-Fi 详情（SSID、信号、协商速率、信道）纳入定位权限——**这不受程序控制**：
即使直接调用 `netsh wlan show interfaces` 或 WlanAPI，系统也会返回“需要定位权限”（错误 5）。
蓝牙不在定位权限限制内；蓝牙电量可以直接读取，信号则在设备发出 BLE 广播时读取实时值。权限关闭时：

- 面板 Wi-Fi 卡片显示“已连接 · 详情需权限”，并给出两步操作说明和可点击的设置链接；
- 小窗轮播显示“Wi-Fi 状态 已连接（需定位权限）”；
- 托盘菜单也有“打开定位权限设置”。

开启步骤：

1. 打开 **设置 → 隐私和安全性 → 定位**；
2. 打开 **定位服务**；
3. 向下打开 **让桌面应用访问你的位置**；
4. 不用重启，程序每 1–5 秒会重新读取，几秒内就会显示真实 RSSI。

> 系统自带的 Wi-Fi 列表能显示信号，是因为它是微软自己的组件、天然具备定位能力；
> 第三方桌面程序必须在上面第 3 步里被授权，否则 `netsh` 和 WlanAPI 都会返回错误 5。
> 蓝牙不在定位权限限制内；电量可以直接读取，信号强度取 BLE 广播的实时值。

### 关于帧率

Windows 没有免提权的 FPS 接口。程序按顺序尝试两条路：

1. **PresentMon（管理员）**：ETW 实时会话汇总每个进程的呈现帧数，优先取**当前前台窗口**
   的进程。启动前会校验该工具的哈希与数字签名（见「安全说明」）。部分机器（如本机）ETW
   实时会话会大量丢事件，此时 PresentMon 拿不到数据。
2. **屏幕刷新采样（备用，默认生效）**：每约 8 ms 抓取前台窗口居中的 720×400 区域，
   统计每秒画面真正变化的次数，结果即为该窗口的实时帧率（视频 / 游戏 / 动画 UI 都适用，
   实测 62 fps 动画测出 62–68 fps）。采样上限约 60 FPS；静态窗口显示 0 并标注「无出帧」。

哪个来源可用就用哪个，界面上不再区分；前台是桌面或本悬浮窗时会自动沿用上一个真实应用。

tools/PresentMon.exe    帧率采集工具
app/
  config.py             配置读写
  pdh.py                PDH 计数器封装
  win32.py              Win32 辅助（穿透、置顶、开机自启动、网关、刷新率、热键）

## 安全说明

- **帧率工具校验**：启动 `tools/PresentMon.exe` 前会同时校验 SHA-256 与 Authenticode 签名，
  任一不通过就不启动，界面显示「PresentMon 校验失败」。更换该工具后需同步更新
  `app/collectors/fps.py` 里的 `_PRESENTMON_SHA256`。
- **系统命令使用绝对路径**：`netsh`、`powershell`、`cmd` 均从 `%SystemRoot%\System32` 下解析，
  不会从当前工作目录加载同名程序。
- **目录权限**：程序目录只应允许管理员写入。若放在共享/非系统盘的用户可写目录中，
  其他本地账户可以替换 `main.py` 或 `PresentMon.exe`，等下次管理员启动时获得提权执行。
  建议把目录移动到 `%ProgramFiles%`，或收紧为「用户与管理员可写、普通用户只读」：

  ```bat
  icacls "D:\小工具" /inheritance:r
  icacls "D:\小工具" /grant:r "*S-1-5-18:(OI)(CI)F" "*S-1-5-32-544:(OI)(CI)F" "%USERNAME%:(OI)(CI)F" "*S-1-5-32-545:(OI)(CI)RX"
  ```

- **提权启动**：`以管理员身份启动.bat` 会以管理员权限运行本目录中的 Python 代码，
  只在确认目录不可被其他用户修改时使用；日常使用 `启动监控.bat` 即可。

## 常见问题

- **小窗点不动**：已开启鼠标穿透（小窗右上角有小锁），按 `Ctrl+Alt+L` 解锁。
- **托盘图标找不到**：Windows 11 收进了“^”溢出区，可拖到任务栏常驻。
- **CPU 温度偏高**：这是 ACPI 热区读数，高负载游戏本 70–80 °C 属正常范围，精确核心温度需专用工具。
- **Wi-Fi 显示需定位权限**：见上一节。若提示「当前进程权限受限（低完整性）」，
  说明程序是被某个受限终端/沙箱启动的，Windows 会拒绝 WLAN 查询；
  请退出后从资源管理器双击 `启动监控.bat`（正常双击即可，普通权限就够）。
- **蓝牙没有电量**：经典蓝牙（手机等）Windows 不提供电量，只有 BLE 设备能从 GATT 读取。
- **界面太大 / 太小**：托盘右键 →「设置…」→ 拖动「界面缩放」滑块（60%–140%），松手后会自动重启
  应用生效；缩放只作用于性能监控悬浮窗（小窗和完整面板），设置窗口与托盘保持原尺寸。缩放值保存在
  `config.json` 的 `ui_scale`。
- **蓝牙信号是怎么来的**：设备正在广播时用 BLE 广播的实时 RSSI；连上后不再广播的设备（很多鼠标、
  键盘如此）回退到 Windows 设备关联缓存值——它是系统最近一次真实测量，可能略有延迟。把鼠标悬停
  在 dBm 上会显示当前来源。只有系统和广播都拿不到值时才显示 `--`。
- **想调锁定后的透明度 / 开机自启动**：右键托盘图标 →「设置…」，在设置窗口里调整。透明度 0–100%
  （0% 为正常玻璃背景，100% 时背景完全透明），自动保存到 `config.json` 的 `lock_alpha`；开机自启动
  通过当前用户启动项（`HKCU\...\Run`）实现，无需管理员权限。
- **想少显示一些指标**：托盘右键 →「设置…」→「自定义显示内容」→ 点进分类，关掉不需要的项。
  全部关掉的卡片会自动隐藏；想恢复就点「恢复全部显示」。
